CORE CAPABILITIES

Engineered for Android TV & Leanback

Built for smooth hardware-accelerated playback on the big screen, effortless D-pad remote control, and clean playlist organization without ads or trackers.

ExoPlayer / Media3 Acceleration

Hardware-accelerated video decoding powered by AndroidX Media3 (ExoPlayer) supporting H.264, HEVC (H.265), AV1, AC3/EAC3 audio, and embedded subtitles.

M3U & Xtream Codes Support

Import local or remote M3U/M3U8 playlists and Xtream Codes API portals with fast category grouping, live search, and multi-playlist switching.

Lightweight & Ad-Free

100% open-source codebase on GitHub with zero advertisements, zero analytics trackers, and local on-device storage for your playlists and favorites.

INSTALLATION

Install zultraTV on Android TV

Sideload the signed APK onto your Android TV or Google TV device using Wireless ADB, or compile directly from source.

1 Download Release APK Download the latest .apk from GitHub Releases.
2 Enable ADB Debugging Turn on Developer Options and ADB Debugging in your Android TV settings.
3 Connect & Install Push the APK to your Android TV box or stick over your local network using ADB.
Sideload over Wi-Fi with Wireless ADB: 
adb connect <ANDROID_TV_IP>:5555
adb install -r zultraTV-release.apk
Clone the repository and build the release APK with Gradle (JDK 17+): 
git clone https://github.com/zultra0/zultraTV.git
cd zultraTV
./gradlew assembleRelease

The compiled APK output will be located in app/build/outputs/apk/release/.
